# weather-predictor
A machine learning project that predicts temperature using weather data with Linear Regression in Python.# Weather Prediction Using Machine Learning

## Overview
This project predicts temperature using machine learning techniques in Python.  
The model is trained using historical climate data from Delhi and uses Linear Regression to predict mean temperature.

The project also generates graphs for prediction analysis and feature correlation.

---

## Features
- Data cleaning and preprocessing
- Feature engineering using month extraction
- Temperature prediction using Linear Regression
- Model evaluation using RMSE and R2 Score
- Prediction graph generation
- Correlation heatmap visualization

---

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- VS Code

---

## Dataset
Dataset used:
- Daily Delhi Climate Dataset

Columns used:
- Humidity
- Wind Speed
- Mean Pressure
- Month
- Mean Temperature

---

## Machine Learning Model
The project uses:
- Linear Regression

The model is trained on 80% of the dataset and tested on the remaining 20%.

---

## Evaluation Metrics
The following metrics are used:
- RMSE (Root Mean Squared Error)
- R2 Score

---

## Output
The project generates:
- Actual vs Predicted Temperature Graph
- Correlation Heatmap

Both graphs are saved in the `outputs` folder.
